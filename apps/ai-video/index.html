Gemini API cá nhân

API Key được lưu trên trình duyệt của bạn. Không ghi vào Google Sheet. Khi tạo bằng Gemini, key sẽ được gửi qua Apps Script của bạn để gọi Gemini.

Lưu ý: Thiên Kim chỉ hỗ trợ tạo prompt thông minh. Người dùng tự mở công cụ AI bằng tài khoản của mình và tự dùng credit của mình.

1. Thông tin sản phẩm

Nếu có link, hệ thống ưu tiên lấy mô tả, giá đang hiển thị, khuyến mãi/voucher/flash sale từ trang sản phẩm hoặc web hãng.
Tập trung mô tả sản phẩm. Nếu link không đọc được, app sẽ ghi rõ phần nào là gợi ý.
Ưu tiên lấy đúng giá đang hiển thị trên website.
Nếu nhập ô này, prompt sẽ ưu tiên hiển thị giá bạn mong muốn.
Bấm “Thay đổi” để xóa trắng và nhập khuyến mãi theo ý bạn.
SĐT và địa chỉ sẽ lưu trên trình duyệt để tự điền ở các phiên sau.

2. Cấu hình nhanh

Nếu có nhân vật sẵn, hãy upload file trước. Hệ thống sẽ tự chuyển sang chế độ dùng file riêng.
Nếu không chọn bối cảnh, AI sẽ dựa trên mô tả ngắn và nơi bán để dựng cảnh.

3. Bản PROMPT VIP có quyền chỉnh sửa

Prompt được ẩn cho đến khi bạn bấm “Tạo prompt” hoặc “Tạo bằng Gemini”. Bạn có thể sửa trực tiếp rồi bấm ❤️ để copy.

Cách dùng sau khi copy

  1. Bấm ❤️ Copy Prompt VIP.
  2. Chọn công cụ bên dưới để mở tab mới.
  3. Đăng nhập bằng tài khoản của người dùng.
  4. Dán prompt và tạo ảnh/video.
  5. Tải file về để đăng TikTok, Facebook, YouTube hoặc Zalo.

4. Đóng góp & phản hồi

Gửi góp ý để Thiên Kim ghi nhận vào Google Sheet. Nếu có phản hồi, lần sau bạn mở lại app sẽ thấy nội dung phản hồi.

Xác nhận file upload

Bạn đã chọn dùng file riêng. Sau khi copy prompt, bạn cần upload đúng file đó lên công cụ AI để kết quả khớp với prompt.

API tài khoản

Dán Gemini API Key của tài khoản này. Key chỉ lưu trong trình duyệt đang dùng.

Hướng dẫn lấy Gemini API Key

  1. Mở Google AI Studio bằng tài khoản Google muốn sử dụng.
  2. Vào mục API Key / Get API key.
  3. Tạo key mới, copy key và quay lại app.
  4. Bấm API tài khoản 1/2/3, dán key, bấm Hoàn tất.
  5. Bấm lại tài khoản đó và chọn Kiểm tra API. Màu xanh là dùng được, màu đỏ là lỗi hoặc hết credit.

Bảo mật: Key lưu trên localStorage của trình duyệt. Nếu xóa cache/cookie, đổi máy hoặc đổi trình duyệt thì sẽ mất. Không nên dùng máy công cộng.
