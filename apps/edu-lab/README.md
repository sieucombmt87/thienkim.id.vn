# TK-EDU-LAB • TKver6.1

Module học tập gắn vào Card số 2 “🎓 Học hỏi” của thienkim.id.vn.

## Điểm mới TKver6.1

1. Bổ sung bộ định tuyến nội dung: biết bài/câu hỏi nằm ở chuyên trang nào, module nào, thư mục/đường dẫn nào.
2. Bổ sung kho duyệt đáp án 3 nguồn: AI, phụ huynh/giáo viên, admin/người ra đề.
3. Hiển thị màu kiểm duyệt:
   - Xanh: 3 nguồn thống nhất.
   - Vàng: thiếu nguồn xác nhận hoặc còn chờ duyệt.
   - Đỏ: có xung đột đáp án, kể cả trường hợp 2 nguồn giống nhau nhưng 1 nguồn khác.
4. Giữ lại bài test demo có thời gian, đảo câu hỏi, đảo đáp án, tự nộp khi hết giờ.
